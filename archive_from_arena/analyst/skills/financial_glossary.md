# Grep Keyword Cheat Sheet

When a question uses these terms, grep for the SHORT keyword shown:

| Question says | Grep for |
|---|---|
| national defense expenditures | `defense` |
| Veterans' Administration | `veterans` |
| customs duties | `customs` |
| internal revenue | `internal revenue` |
| individual income taxes | `income` |
| corporation income taxes | `corporation` |
| employment taxes / FICA | `employment` |
| estate and gift taxes | `estate` |
| interest on the public debt | `interest` + `debt` |
| currency in circulation | `currency` + `circulation` |
| Highway Trust Fund | `highway` |
| Exchange Stabilization Fund | `stabilization` |
| Treasury bills / notes / bonds | `bills` or `notes` or `bonds` |
| public debt outstanding | `debt` + `outstanding` |
| budget receipts / expenditures | `receipts` or `expenditures` |
| surplus or deficit | `surplus` or `deficit` |
| gross saving / personal saving | `saving` |
| foreign exchange | `foreign` + `exchange` |

Units: ALWAYS check the line above the table header.
- "(In thousands)" → raw "1,234" = $1,234,000
- "(In millions)" → raw "1,234" = $1,234,000,000
- Footnotes (3/, r/, p/) are NOT part of the number — strip them.
