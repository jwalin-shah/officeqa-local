FEATURES
================================================================================

Agreement Detection:
  - Full agreement (all 3 agree) → 15% confidence boost
  - Partial agreement (2 out of 3) → 5% confidence boost
  - No agreement (all differ) → 5% confidence penalty
  - Tolerance: 1% relative difference for numeric values

Value Comparison:
  - Exact match detection
  - Close match detection (within tolerance)
  - Significant disagreement flagging

Confidence Management:
  - Base confidence from input results
  - Agreement-based boosting (capped at 0.99)
  - Penalty for disagreement
  - Transparent confidence tracking

Voting Details:
  - Full breakdown of all 3 strategy results
  - Individual confidences preserved
  - Human-readable reasoning
  - Risk flags for problematic cases

Edge Cases Handled:
  ✓ All 3 return None

API OVERVIEW
================================================================================

Main Class: ConsensusVoter

  vote(strict_result, fuzzy_result, contextual_result) -> Dict
    Compare 3 results and return winning consensus with voting details

  check_agreement(value1, value2, tolerance=0.01) -> str

================================================================================
CONFIDENCE BOOST MATHEMATICS
================================================================================

Full Agreement (all 3 valid results agree):
  boosted = base * 1.15, capped at 0.99
  Example: 0.85 * 1.15 = 0.9775
  Example: 0.99 * 1.15 = 1.1385 → 0.99 (capped)

Partial Agreement (2 out of 3 agree):
  boosted = base * 1.05, capped at 0.99
  Example: 0.85 * 1.05 = 0.8925
  Example: 0.95 * 1.05 = 0.9975 → 0.99 (capped)

No Agreement (all differ or only 1 valid):
  boosted = base * 0.95
  Example: 0.99 * 0.95 = 0.9405
  Example: 0.70 * 0.95 = 0.665

================================================================================
KEY DESIGN DECISIONS
================================================================================

1. Consensus > Confidence
   Rationale: Three independent approaches agreeing is stronger signal than
   single high-confidence result

2. Tolerance-Based Grouping
   Rationale: Handles rounding differences and floating-point precision
   Tolerance: 1% relative difference

3. Confidence Capped at 0.99
   Rationale: Leave room for unexpected errors, never claim perfection

4. Risk Flags Instead of Exceptions
   Rationale: Allow caller to decide how to handle edge cases

5. Full Voting Breakdown in Output
   Rationale: Enable debugging and audit trails
